# 开发规范细则

## 文件验证

```
写入后必须 stat 验证真实落盘，不能只用 ls（overlay 文件系统会欺骗）
stat 报 No such file = 写入失败
```

## 后端接口修改流程

1. 先查 `custom_routes.js` 是否已拦截该路由
2. 再决定是改路由层还是直接加新接口
3. 改完重启 Agent

## UI 修改流程

1. 改 index.html / 前端代码
2. **重启 Agent**
3. 真机访问验证

## YAML 写入

- 用专用 YAML 函数，绝不手拼字符串
- 注意缩进一致性

## 凭证管理

- 凭证放 `.env`，绝对不进代码库
- alist 密码已泄露事件 → 强烈建议改密
