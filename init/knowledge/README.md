# 📚 Hermes 知识库

这是 Hermes 的持久化知识库（Obsidian 兼容：.md + frontmatter + [[wikilink]]）。

## 使用方式

- 左侧菜单「知识库」浏览 / 编辑笔记
- 正文用 `[[笔记名]]` 串联相关笔记（自动生成反向链接）
- 对话中的技能使用、重要结论会自动沉淀到本库
- 与 AI 的 Obsidian 技能共用同一 vault（OBSIDIAN_VAULT_PATH）

## 建议目录

- `概念/` — 领域知识、术语
- `技能使用/` — 每次对话调用的技能记录（自动）
- `对话沉淀/` — 重要对话的要点提炼（自动）
- `项目/` — 项目上下文、决策记录
